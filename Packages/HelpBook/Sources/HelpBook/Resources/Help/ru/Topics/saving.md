# Сохранение

> Красным отмечены байты, отличающиеся от файла на диске. Сохранение записывает их в файл, и красный цвет снимается.

- **⌘S — Сохранить.** Записывает документ панели обратно в его файл. Безымянный документ вместо этого откроет диалог сохранения и предложит выбрать имя файла.
- **⇧⌘S — Сохранить как…** Записывает в новое место, и панель переходит на новый файл.
- **Файл ▸ Вернуться к сохранённому** отбрасывает правки и перечитывает файл с диска.
- **Файл ▸ Записать в исходный файл** — третий вариант: для [[topic:fragments|панели фрагмента]] он пишет фрагмент обратно в образ, откуда он взят, а не в файл.

## Что не сохранено

Изменённые байты показаны **красным**, пока не сохранены, а в заголовке панели указано, что документ изменён. Сохранение снимает оба признака.

## Если файл изменился, пока вы работали

ByteRipper следит за открытым файлом. Если его перезапишет другая программа — например, программатор перечитает чип памяти в тот же путь, — программа это обнаружит и сообщит, вместо того чтобы при последующем сохранении молча записать поверх нового содержимого.

## Документы без файла

Часть документов не имеет ни имени, ни пути по своему устройству, поэтому ⌘S спрашивает, куда их записать:

- **Файл ▸ Новый файл** (⌘N).
- Результат [[topic:join-duplicate|объединения]]: соединение двух дампов даёт *новый* образ, который ⌘S не должен записать поверх одной из половин.
- Результат **Дублировать**.
- Часть, вытащенная из образа.

! **Сохранить как…** записывает исправленный образ в новый файл и оставляет исходный без изменений. Средствами программы восстановить исходный дамп после его перезаписи невозможно.
