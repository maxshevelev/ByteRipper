# Объединение и дублирование

> Дампы двух чипов памяти в один образ и копия «до» для правки.

## Объединение: дампы двух чипов SPI в один образ

На многих платах BIOS разложен по двум чипам памяти. Прочитайте обе, а дальше:

- **Файл ▸ Дописать файл в конец…** — байты выбранного файла встают после содержимого панели.
- **Файл ▸ Вставить файл в начало…** — встают перед ним.

Теперь весь BIOS — один образ, и с ним нормально работает всё: сравнение, поиск, [[topic:tool-uefi|панель UEFI]], которая ждёт один непрерывный образ.

Шов записан как разрез [[topic:segments|сегмента]], поэтому **Сохранить всё отдельными файлами** вернёт вам обе половины по той же границе, готовые к записи каждая в свой чип.

Отсюда следуют две вещи, о которых стоит знать:

- **У объединённого документа нет файла.** Он безымянный, поэтому ⌘S спросит, куда его класть, и не сможет случайно перезаписать одну из половин.
- **Объединение — один шаг отмены.** ⌘Z убирает добавленные байты *и* возвращает панель к тому файлу, из которого она была открыта.

## Дублирование: копия дампа как он есть

**Файл ▸ Дублировать** копирует содержимое панели в свободную панель новым несохранённым документом. Доступно в однофайловом режиме, где есть куда копировать.

Это самый быстрый способ править со страховкой: дублируйте, правьте копию и смотрите, как различия появляются рядом с оригиналом по мере набора. Закончив, сохраните ту половину, которая правильная.
