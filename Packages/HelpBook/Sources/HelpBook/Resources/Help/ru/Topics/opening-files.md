# Открытие файлов: одна панель или две

> Во вкладке две файловые панели. Один файл — обычный редактор, два — ещё и сравнение. Править можно в обеих панелях.

От того, сколько из двух панелей занято, зависит, как работает окно:

- **Открыт один файл** — однофайловый режим. Окно работает как hex-редактор этого файла: правка, поиск и инструментальные панели работают как обычно.
- **Открыты два файла** — режим сравнения. Дампы стоят рядом (или один над другим, см. **Вид ▸ Сменить расположение файловых панелей**), и каждый различающийся байт закрашен.

Вторая панель необязательна. Ничего, кроме самого сравнения, второго файла не требует.

## Способы открыть дамп

- **Файл ▸ Открыть…** (⌘O). Если обе панели пусты, первые два выбранных файла займут их; если свободна одна — файл откроется в ней; если заняты обе — заменит **активную** панель. Остальные выбранные файлы не откроются.
- **Перетаскивание.** Потяните файл на окно — полосы приёма покажут, куда он попадёт: заменить эту панель, открыть рядом или открыть в новой вкладке. Перетащите два файла сразу — второй откроется во второй панели, если она свободна.
- **Файл ▸ Недавние документы** — дампы, с которыми вы работали в последнее время.
- **Из Finder**, если ByteRipper назначен приложением для файлов с этим расширением (см. [[topic:settings|Настройки]]).
- **Файл ▸ Новый файл** (⌘N) создаёт пустой безымянный файл — место, куда можно вставить байты.

## Панели, вкладки и окна

В заголовке каждой панели — имя файла и признак несохранённых изменений; размер файла стоит в строке состояния под ней. ✕ в заголовке закрывает эту панель и оставляет вторую открытой.

В окне может быть несколько вкладок (**Файл ▸ Новая вкладка**, ⌘T), у каждой своя пара файловых панелей для сравнения. Так на одном экране держат сразу несколько плат: в одной вкладке сравниваются дампы BIOS, в соседней — дампы EC.

## Если файл уже открыт

Один файл может быть открыт одновременно только в одной панели, программа за этим следит:

- **В другой панели этой же вкладки** — откажет с предупреждением. Один и тот же дамп не может лежать в обеих панелях, поэтому сравнить файл с самим собой не получится. Свои правки видно и так — по красным байтам; а если нужны именно две копии рядом, сделайте **Файл ▸ Дублировать**.
- **В другой вкладке или в другом окне** — предложит выбор: показать файл там, где он сейчас открыт, или перенести панель с этим файлом из другого окна в текущую вкладку.
- **В этой же панели** — перечитает файл с диска. Если в панели есть несохранённые правки, сначала спросит: перечитывание их отбросит.

! Замещение файла в панели с несохранёнными правками спрашивает подтверждение. Восстановить отменённую запись нельзя, несохранённые данные будут потеряны.
