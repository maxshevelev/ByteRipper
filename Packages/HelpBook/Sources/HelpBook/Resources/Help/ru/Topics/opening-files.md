# Открытие файлов: одна панель или две

> Во вкладке две файловые панели. Один файл — обычный редактор, два — ещё и сравнение. Править можно в обеих панелях.

От того, сколько из двух панелей занято, зависит, как работает окно:

- **Открыт один файл** — однофайловый режим. Окно работает как hex-редактор этого файла: правка, поиск и инструментальные модули работают как обычно.
- **Открыты два файла** — режим сравнения. Дампы стоят рядом (или один над другим, см. **Вид ▸ Сменить расположение файловых панелей**), и каждый различающийся байт закрашен.

Вторая панель необязательна. Ничего, кроме самого сравнения, второго файла не требует.

## Способы открыть дамп

- **Файл ▸ Открыть…** (⌘O). Файл заменяет **активную** панель и сам по себе вторую панель не создаёт. Только если обе панели пусты, первые два выбранных файла займут их. Остальные выбранные файлы не откроются.
- **Файл ▸ Сравнить с…** (⌥⌘O) открывает файл в другой панели: свободной, а если свободной нет — в неактивной. Так добавляется второй файл для сравнения. В **Файл ▸ Недавние документы** при зажатом ⌥ строка выполняет ту же команду.
- **Перетаскивание.** Потяните файл на окно — полосы приёма покажут, куда его можно положить: заменить эту панель, присоединить к началу или к концу, открыть для сравнения или открыть в новой вкладке. Пока файл над окном, видны все полосы, полупрозрачные; полоса под указателем выделена, и файл попадёт именно в неё. Перетащите два файла сразу — второй откроется во второй панели, если она свободна.
- **Файл ▸ Недавние документы** — дампы, с которыми вы работали в последнее время.
- **Из Finder**, если ByteRipper назначен приложением для файлов с этим расширением (см. [[topic:settings|Настройки]]).
- **Файл ▸ Новый файл** (⌘N) создаёт пустой безымянный файл — место, куда можно вставить байты.

## Панели, вкладки и окна

В заголовке каждой панели — имя файла и признак несохранённых изменений; размер файла стоит в строке состояния под ней. ✕ в заголовке закрывает эту панель и оставляет вторую открытой. Закрытие последнего файла вкладки закрывает и саму вкладку, если открыты другие вкладки, а в этой нет [[topic:bookmarks|закладок]] и [[topic:fragments|панелей фрагментов]]; последняя вкладка программы остаётся открытой, пустой.

В окне может быть несколько вкладок (**Файл ▸ Новая вкладка**, ⌘T), у каждой своя пара файловых панелей для сравнения. Так в одном окне ведут несколько независимых сравнений: в одной вкладке — дампы BIOS, в соседней — дампы встроенного контроллера.

## Если файл уже открыт

Один файл может быть открыт одновременно только в одной панели, и программа это контролирует:

- **В другой панели этой же вкладки** — программа откажет и укажет причину. Один и тот же файл не может занимать обе панели, поэтому сравнить файл с самим собой невозможно. Несохранённые правки и без того обозначены красным, а если нужны именно две копии рядом, их даёт команда **Файл ▸ Дублировать**.
- **В другой вкладке или в другом окне** — предложит выбор: показать файл там, где он сейчас открыт, или перенести панель с этим файлом из другого окна в текущую вкладку.
- **В этой же панели** — программа перечитает файл с диска. Если в панели есть несохранённые правки, она сначала спросит, поскольку перечитывание их отбрасывает.

! Замещение файла в панели с несохранёнными правками запрашивает подтверждение. Восстановить отброшенные правки невозможно.
